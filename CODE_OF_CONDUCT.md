# Community code of conduct

Participants should be respectful, constructive and inclusive. Critique
technical ideas with evidence, not personal attacks. Respect privacy,
accessibility needs and differing backgrounds.

Harassment, threats, discrimination, doxxing, sexual misconduct, impersonation
and intentional disclosure of personal documents or secrets are unacceptable.
This applies to project issues, pull requests, discussions and project-run
events.

Maintainers may remove content, limit participation or exclude contributors
when necessary to protect the community, considering context and proportionality.
Explain decisions where doing so does not expose private information. Appeals
may be requested; a maintainer involved in a complaint should not decide it alone.

For a conduct concern, use a private contact method listed on the maintainer's
GitHub profile. If none is available, request a private contact channel without
posting incident details or identifying other people publicly. Do not use
GitHub security advisories for non-security conduct reports.

Private reports should be shared only with people needed to address the issue.
The preview project does not promise continuous moderation or response times.
